After hearing a little too much hype on "Vibe Coding" I decided to jump on the
train and give it a try. Using this approach, I've been building a simple
"digital wallet" Android app in my spare time for the last couple weeks.

{% include figure.liquid loading="eager" path="assets/img/wallet-app/app-overview.png" class="img-fluid rounded z-depth-1" %}
Wallet app's current progress

Yes, there are existing wallet apps. But for a variety of reasons, I was unhappy
with what was available. This project felt like a good excuse to lean heavily
on my AI assistant.

Writing a wallet app is not the pinnacle of software engineering, but
it's just hard enough to teach something useful about the tools involved. In
addition to building a functional app, my goals were:

- Familiarize myself with AI coding tools in practice
- Learn the strengths and limitations of AI coding agents
- Explore what it feels like to build and mange code that I don't fully understand

Along the way I learned unexpected lessons on AI code smells, version management
strategies for agent coding, refactoring strategies, design strategies, and more.
I'm working on a presentation targeted for JCSDA and I'll expand into a
more detailed project write-up here.
